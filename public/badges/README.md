# Badge Icons

This directory contains SVG icons for Ghost Debugger Badges.

## Required Badge Icons

The following badge icons should be placed in this directory:

- `loop-master.svg` - Loop Master badge
- `conditional-champion.svg` - Conditional Champion badge
- `logic-legend.svg` - Logic Legend badge
- `first-bug-fixed.svg` - First Bug Fixed badge
- `hint-free-hero.svg` - Hint-Free Hero badge
- `persistent-debugger.svg` - Persistent Ghost Helper badge
- `perfect-start.svg` - Perfect Start badge
- `ghost-whisperer.svg` - Ghost Whisperer badge

## Icon Guidelines

- Format: SVG
- Size: 80x80px recommended
- Style: Ghost-themed, kid-friendly
- Colors: Match game palette (#6B46C1, #A3FF00, #00D9FF)

## Temporary Fallback

Until custom icons are created, the badge system uses emoji icons (🏆 for earned, 🔒 for locked).
